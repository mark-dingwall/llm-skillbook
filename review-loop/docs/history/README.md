These documents and research inputs describe the superseded pre-redesign
review-loop workflow, its tier-and-roster plan, and its self-review. They are
retained as historical context, not as implementation or operating authority.

Current implementation work is governed by the live [skill](../../SKILL.md),
its shipped operational guidance, and the controller. The [Review Loop
Redesign](../superpowers/specs/2026-08-14-review-loop-redesign-design.md)
remains useful design lineage for understanding how the current controller
evolved; it does not replace those live sources.
