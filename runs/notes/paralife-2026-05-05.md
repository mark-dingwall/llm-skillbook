### What this pair *shows this time*

1. **Modes agree on a verified-fix verdict.** When the codebase is "already fixed" and the prompt enumerates explicit decisions to verify, both modes converge on confirming all of them. Mode is most differentiating during *discovery*; for *verification* the signal collapses.
2. **Codex verdict is mode-sensitive on borderline severity.** Same bug, REF → DO-NOT-SHIP, INL → SHIP-WITH-FOLLOWUPS. If you're using codex's verdict as a gate, mode matters; if you're using its findings as triage candidates, mode is noise.
3. **Claude INL adapter is now provably broken across 5 paired runs.** Output telemetry under-reports by 4+ orders of magnitude. Stop investigating, start fixing. Bytes-on-the-wire is the only reliable INL volume proxy until then.
4. **Gemini's mode-sensitivity is the most reproducible mode signal in the dataset.** REF → tools/exploration, INL → prompt-only. Codex doesn't flip this hard; opencode telemetry is unreadable; claude is reviewer-stable in REF and broken in INL.
5. **`PerceptionBroadcaster`/`@Order(100)` doc rot is now a 3-paired-run stable miss.** Pass-4 review (2026-05-04) flagged it; 19.1 fix swept CLAUDE.md but missed the source comments; this pair flags it again. The fix is one `sed` away — file the housekeeping commit.
