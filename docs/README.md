# Repository planning records

This directory is the human entry point for repository-wide design decisions
and implementation plans. Start with the [approved documentation design](superpowers/specs/2026-08-18-repository-documentation-design.md)
and its [implementation plan](superpowers/plans/2026-08-18-repository-documentation.md)
when you need the current intent or delivery sequence.

Designs that belong to one component stay with that component. Dated plans,
reviews, transcripts, and other records remain useful as historical evidence,
but active entry points identify them as non-authoritative when they no longer
describe the current repository.
