## Methodology

For a clean comparison run:
- Run BOTH modes against identical inputs in the recommended order.
- Wait at least 30 minutes between modes if gemini fallback fired in the first run (quota cooldown — exhaustion in run 1 cascades into run 2 and confounds the comparison).
- Run from separate sessions when possible so cache state doesn't bias claude's tool-call behaviour.
- The harness writes one row to `runs/runs.jsonl` per run automatically. Pass `--no-harvest` to opt out for a given run.
